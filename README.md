# PCK Studio

**PCK Studio** est un éditeur open source de fichiers **`.PCK`** pour les anciennes versions de **Minecraft Console Edition**. Il permet d'explorer et de personnaliser les ressources contenues dans ces archives.

> **Dépôt non officiel.** Ce dépôt reprend un logiciel existant : je ne suis pas le développeur original de PCK Studio. Le [projet d'origine est disponible ici](https://github.com/LCERD/PCK-Studio).

## Fonctionnalités

- Ouvrir, modifier et enregistrer des archives `.PCK`.
- Ajouter, remplacer ou supprimer des textures, skins, sons, animations et autres ressources.
- Consulter les images grâce à l'aperçu intégré.
- Modifier des ressources de localisation pour différentes langues.
- Travailler sur des packs personnalisés pour les éditions console historiques de Minecraft.

## Formats pris en charge

| Fichier | Utilisation |
| --- | --- |
| `.PCK` | Archives de ressources du jeu |
| `.LOC` | Localisation et traductions |
| `.GRH` / `.GRF` | Règles et données du jeu |
| `audio.pck` | Références audio et musicales |
| `.COL` | Tables de couleurs |

La prise en charge exacte dépend de la version du logiciel et des fichiers utilisés.

## Utilisation

1. Lancez PCK Studio sur votre PC Windows.
2. Ouvrez un fichier `.PCK` compatible.
3. Parcourez les ressources et effectuez les modifications souhaitées.
4. Enregistrez votre travail sur une copie du fichier original.

**Conseil :** conservez toujours une sauvegarde de vos fichiers avant de les modifier.
